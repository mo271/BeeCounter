# Sample images

Test photos for manually checking detection quality and for automated tests.
GPS tags have been stripped from the EXIF data; orientation tags are kept.

Sanity checks:

- `IMG_8283.JPG` contains no bees at all (expected count: 0).
- `20200509_150918.jpg` contains exactly one bee, not on a comb.

All other images show bees on frames or top bars, from sparse to very dense.
`PXL_20250714_152753571.jpg` includes a marked queen (blue dot).
